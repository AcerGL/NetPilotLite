# 真实环境手动验收

以下步骤仅由用户在确认可短暂断网后执行。开发和自动测试没有执行真实网卡修改。

1. 保持本地操作，不通过远程桌面测试禁用。记录原 Ethernet / Wi-Fi 状态。确认不是依赖校园网进行远程管理。
2. 双击正式 EXE；先拒绝一次 UAC，确认没有进程运行、网络保持原状；再允许启动。
3. 检查两个下拉框：Intel I219-V 与 Intel AX203 的完整名称和 GUID。未找到已绑定设备时应显示未找到，而非自动改选。
4. 对照 Windows 高级网络设置检查启用/禁用、已启用未连接及链路连接状态。可以先只刷新，确认启动没有改变设备。
5. 手动确认 Wi-Fi 已连接手机热点后，点击禁用以太网；对照 Windows 状态，等待应用重新查询成功。再启用以太网确认恢复；网线始终可插着。
6. 单独禁用/启用 Wi-Fi，应仅改变 Wi-Fi。此步骤可能使唯一可用连接断开，先确认有本地操作条件。应用不会自动重连特定 SSID 或保存密码。
7. 校园网模式仅启用 Ethernet。Wi-Fi 未连接时热点模式应停止；Wi-Fi 禁用时应先询问，再启用并重新检测，未连接时不禁用 Ethernet。
8. 禁用唯一已连接的绑定网卡应有默认取消的警告。远程桌面会话应拒绝禁用，仍允许启用。
9. 检查 Clash Verge 的进程、节点、代理配置，以及虚拟网卡、DNS、网关、Metric。应用没有这些配置的修改入口；网卡禁用本身会自然影响系统路由可用性。
10. 修改主题/背景、移动缩放窗口、设置关闭至托盘，退出再启动确认保留。移走原始自定义图片后，已复制的背景仍应可用。
11. 对照 LOCAL_UPDATE.md 执行正式目录升级，确认 EXE 路径、桌面快捷方式、两张绑定及全部偏好保留，升级前后网卡状态一致。
12. 受保护目录更新、UAC 取消、杀毒软件占用、受限账户及真实重启恢复，需要在用户认可的测试环境验收。不要在重要网络使用期间做物理断电测试。

遇到错误请保留 Windows/CM 错误码及更新日志，勿删除未提交事务的备份。设备控制失败不会擅自改动其他网卡，也不会自动恢复用户禁用的网卡。
