## 绘图问题与修复

基线 `app.c::place/layout` 对每个子控件调用 `MoveWindow(..., TRUE)`，布局尚未完成便触发重绘；主窗口未使用 `WS_CLIPCHILDREN`，父窗口双缓冲完成后又可能覆盖子控件区域。`WM_ERASEBKGND` 返回已处理，依赖后续完整绘制，却未协调子窗口失效区。基线设置页使用 `ScrollWindowEx(...SW_SCROLLCHILDREN...)` 搬动部分出界控件与旧像素，增加背景错位风险。

修复后：

- 主界面采用保留的 32 位 DIB 内容缓存，封面、背景、卡片及静态文字在同一坐标系合成。滚动只截取对应区域，避免重复解码、缩放及文字排版。
- 缓存仅在尺寸、主题、内容或图片变化时更新。图片读取、复制与解码仍在后台线程；不透明图片缩放使用 HALFTONE。
- 布局使用 `DeferWindowPos`，禁止复制旧像素和逐控件即时刷新，布局完成后统一失效；父窗口明确裁剪子窗口。
- 设置中心的内容有独立裁剪视口，导航和页标题固定，不再搬运旧屏幕像素。
- 窗口缩放、主题、字体和图片变化会使相应缓存失效，退出释放缓存、字体、画刷与系统通知订阅。
- 接口/IP 变化通知合并到 400 ms 后读取。30 秒兜底读取代替原 5 秒轮询；快照未变化时不重建网卡列表或重写文字。后台读取不再让按钮反复变灰。
- 配置写入合并到 300 ms 后进行；退出、更新前强制完成保存。没有把网络修改转移到 UI 线程。

未采用全窗口 `WS_EX_COMPOSITED`：试验中它使平均耗时从 26.8 ms 增至约 29 ms。主窗口使用显式内容缓存；设置窗口保留系统子窗口合成以稳定控件绘制。

## 测量方法

真实 Windows 桌面运行 Release x64 测试程序，真实网卡写入入口在编译期移除。`--perf` 使用 QueryPerformanceCounter、GetProcessTimes、GetGuiResources、K32GetProcessMemoryInfo，执行相同 600 次滚动、每 20 次一次缩放，包含自定义图片背景和真实 GDI 绘制。不是 Visual Studio 抽样分析器，不代表任意电脑的帧率。

基线：平均 26.815 ms，P95 41.635 ms，最大 72.433 ms，总 CPU 10265.62 ms，工作集 41936 KiB。最终优化：平均 11.177 ms，P95 21.409 ms，最大 62.198 ms，总 CPU 4109.38 ms，工作集 47704 KiB，GDI 41 → 41。平均耗时下降 58.3%，工作集增加约 5.6 MiB，用于可复用绘图缓存。原始结果见随包 `v110-perf-after.txt`，与 `v110-perf-before.txt` 对照；P95 包含完整缩放重绘，平均耗时不能当作所有帧的上界。

## 设置与浮窗

设置中心有通用、网络适配器、快捷操作、外观、系统托盘、应用网络分流、更新、关于八页。新增自定义封面、卡片透明度、字体缩放、界面间距、动画、浮窗风格/透明度/宽度/强调色/圆角/图标偏好。实时主题预览与主窗口联动；保留原背景和绑定。

托盘点击/右键打开独立 Win32 工具浮窗，双击显示主窗口。按钮调用既有安全网卡流程，显示状态与操作结果；Esc 或失去激活关闭。使用 `Shell_NotifyIconGetRect`、当前显示器工作区及各窗口 DPI 定位。小屏提供滚动，避免底部操作无法触及。

使用文档化 `DWMWA_SYSTEMBACKDROP_TYPE / DWMSBT_TRANSIENTWINDOW`，配合 DWM 圆角及 Buffered Paint 背景 Alpha。失败时使用实色主题。实测 Windows 返回 S_OK；系统仍可因透明效果设置、节能或远程会话降低效果，截图和 API 成功不作为所有系统的毛玻璃保证。Windows 10 回退分支和 Solid 模式有代码/模拟检查，未在真实 Windows 10 上验收。

参考：[Microsoft DWM backdrop](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)、[ScrollWindowEx 子窗口限制](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-scrollwindowex)。

## 手动验收

用已有 1.0.1 的「设置 → 更新 → 从本地文件更新」选择包内 EXE；签名清单放在旁边。覆盖原位置后，绑定、封面、背景和偏好应保留。先拖动滚动条、缩放窗口、切换各设置页、打开托盘浮窗；确认无需网络切换便可完成这些检查。

若自行授权真实网卡测试，确保在本地电脑上操作，先确认手机热点可用，再使用指定网卡按钮；程序会重新查询实际状态，失败显示 Windows 错误码。退出和更新均不自动恢复已禁用网卡。
