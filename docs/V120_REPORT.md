## 2. 紧凑托盘

100% 字体、96 DPI 时：Compact 宽 310 DIP，内容高 272 DIP，含边框外窗约 310 × 274 DIP。Comfortable 默认宽 360 DIP，内容高 308 DIP；宽度设置保留。字体缩放后重新计算行高、按钮高和整体高度，不是整体截图缩小。

保留主题、Acrylic 请求/实色回退、圆角、阴影、两张物理网卡开关及模式按钮。按托盘所在显示器工作区夹紧位置；屏幕过小时允许必要滚动。默认高度下测试未出现垂直滚动条。

模拟检查覆盖 100–200% DPI、100/120/140% 字号、两种密度及带负坐标的工作区。实际本机截图已检查。**没有多台真实不同 DPI 显示器的拖移验收，也没有 Windows 10 实机验收。**

## 3. 应用枚举与限制

- Win32：HKLM 64/32 位及 HKCU 卸载注册表，读取名称、发布者、版本、图标、安装位置及辅助卸载元数据；不执行卸载命令，不用 Win32_Product。
- Store/MSIX：当前用户 Shell AppsFolder 支持的包应用，解析 PFN/AUMID，读取可用名称/发布者/图标。不是所有用户或所有框架包的清单，未知发布者明确显示未知。
- 运行程序：Toolhelp32、QueryFullProcessImageName、包身份 API；显示 PID、可读路径及可用文件元数据。权限不足或进程退出不伪造路径。
- 手动选择：检查本地 PE EXE，多选添加、路径/包身份去重；新增规则默认关闭。候选及完整身份可查看、确认。

真实只读枚举：150 个安装记录/应用，其中 45 个包身份、32 个候选 EXE 路径；362 个运行进程，其中 187 个可读路径、41 个包身份，175 个路径读取受限或进程已退出。数字是本次快照，后续会变化。未记录个人应用名称和完整路径到公开报告。

无法解析时保留条目：DisplayIcon 指向 DLL、卸载器/更新器、无安装位置、多个 EXE、路径不可读、未注册便携程序、受保护进程和包应用。安装目录仅做有界的顶层候选搜索，不递归扫盘。启动器可能不是真正联网进程；可从 Running Processes 添加多个实际 EXE。

应用分流仍是 **Monitor Only**。包身份保存，但当前后端不能验证包的物理出口；找到 EXE、源地址匹配均不等于已强制改道。Clash/VPN/TUN 代理进程与原应用的关联不作虚假承诺。

## 5. 签名与升级安全

在线下载先验证 128 字节发布清单的固定 ECDSA P-256 公钥签名，再下载固定名称 EXE，并核对 SHA-256、产品、AMD64 架构、大小与版本；可用的 GitHub digest 也必须一致。EXE 不高于当前版本则拒绝。点击安装再次验证，确认后复用已有独立原地更新器，其同卷暂存文件也会复验。

Release 1.2.0.0 的固定公钥、产品、大小、版本、x64、SHA-256 验证通过。**没有 Authenticode 证书**，本次采用独立发布清单签名。私钥未进入交付包。签名根沿用原版，不要求用户更换信任密钥。

错误架构负样本已独立签名，清单哈希与 payload 一致，PE Machine 改为 I386 后被验证器拒绝，未执行。下载中断、取消、错误签名和损坏 payload 在模拟传输中被拒绝；这些不是公网故障注入验收。
